# Species Editor 0.3

Copiar el contenido de esta carpeta como `res://addons/species_editor/`.

Incluye:
- Lista y búsqueda de especies por ID/nombre.
- Selección por ruta real del recurso.
- Guardado y revertido sin cache.
- Validación del recurso.
- Selectores de tipos, habilidades, movimientos y especies.
- Edición básica de learnsets y evoluciones.

Antes de usarlo, activar `res://addons/species_editor/plugin.cfg` desde Project > Project Settings > Plugins.
No incluye todavía creación/eliminación física de especies.
